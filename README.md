здесь мини-трекер учебных задач, сделанный двумя способами. первый вариант (v1) сделан по короткому прямому запросу. второй (v2) сначала описан спецификацией в формате openspec (без cli), а потом реализован по ней. отчет лежит в [report.md](report.md).

## как запустить

достаточно скачать html-файл и открыть его двойным кликом в браузере. сервер, установка и интернет не нужны.

- tracker-v1.html - первая попытка, исходная версия до исправлений
- tracker-v1-fixed.html - первая попытка после одного исправления (границы часов 0,5-24 и шаг 0,5)
- tracker-v2.html - вторая попытка, реализация по спецификации

задачи сохраняются в localstorage. чтобы вернуть стартовый пример, нужно очистить данные сайта в devtools (application, local storage).

## что где лежит

- prompts.txt - тексты всех запросов: прямой запрос, спецификация, реализация, исправление
- report.md - отчет: обращения и время, результаты t1-t5, отличия версий, вывод и ограничения
- spec/ - спецификация для v2: proposal.md, specs/tracker/spec.md, design.md, tasks.md
- chat-logs/ - полные ответы модели в обеих попытках
- screenshots/ - скриншоты проверок
- checks/ - скрипт проверок t1-t5 (playwright + chrome) и логи прогонов

## как повторить проверки

```
pip install playwright
python checks/run_checks.py v2 tracker-v2.html screenshots v2
```

в скрипте указан chrome по пути /usr/bin/google-chrome. на другой системе нужно поправить executable_path в run_checks.py или поставить браузер через playwright install chromium и убрать этот параметр.
